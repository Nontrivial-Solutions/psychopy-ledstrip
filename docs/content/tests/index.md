This section contains a collection of integration tests for the plugin. The `xml` files containing
the experiment configurations are found in `./tests/`

Tests are categorized into two cases:

- Happy (:fontawesome-solid-smile:): The test is on the
    [happy path](https://en.wikipedia.org/wiki/Happy_path).
- Unhappy (:fontawesome-solid-frown:): The test is on the
    [unhappy path](https://en.wikipedia.org/wiki/Happy_path#Unhappy_path).
