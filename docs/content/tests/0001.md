## Purpose

Test the normal workflow for configuring multiple Fastrak sessions in PsychoPy within a routine.

configured. Move the Fastrak in space in both sessions.

A Fastrak is connected to the host machine.

## Expected Output

Data output indicates moving Fastrak in both sessions. Session data is different.
